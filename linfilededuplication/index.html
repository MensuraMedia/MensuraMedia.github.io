LinFileDedup

Reclaim disk space by finding duplicates safely.

LinFileDedup finds exact duplicates, visually similar images and near-identical documents, flags probable backups, and lets you reclaim space safely. Nothing is changed until you review the groups and confirm, and removals go to Trash by default.

InstallView on GitHub

What it does

Features

  • 01

    Exact + near matches

    A layered pipeline (size, partial hash, SHA-256, byte-for-byte) finds exact duplicates; perceptual hashing groups similar images.

  • 02

    SpotCheck

    Compare a group side by side: image previews, a synced page-by-page PDF viewer, an inline video player or document snippets.

  • 03

    Multi-source scans

    Scan several folders and drives as one pool; the primary source's copy is kept and cross-drive copies route to Trash.

  • 04

    Fast repeat scans

    A persistent hash cache reuses fingerprints of unchanged files; every match is still byte-verified so the cache never weakens safety.

  • 05

    Backup awareness

    Files that look like backups (~, .bak, copy, dated sets) are flagged with colourblind-safe markers and never removed automatically.

  • 06

    Runs locally

    No accounts, no network, no telemetry; scans are read-only and confirmation is required before anything is removed.

A closer look

Install

Build and install the .deb, or use the installer script for a user or system install.

Requirements

  • Debian 12/13 or Linux Mint
  • GTK 4 + libadwaita (python3-gi)
  • python3-pil
  • python3-imagehash, python3-xxhash recommended
From the .deb
git clone https://github.com/MensuraMedia/linfilededuplication.git
cd linfilededuplication
scripts/build-deb.sh
sudo apt install ./dist/linfilededuplication_0.1.0_all.deb
User install
scripts/install.sh   # ~/.local (user)
System install
scripts/install.sh --system   # /usr/local (sudo)
  • Remove with scripts/uninstall.sh
  • Depends on python3-gi, gir1.2-gtk-4.0, gir1.2-adw-1; optional extras degrade gracefully when absent

Full and current instructions: the README on GitHub.
