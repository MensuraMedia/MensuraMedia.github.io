Language Learning Worksheets

Free worksheets for Japanese and English practice.

A collection of free language learning worksheets, reference charts, flash cards and wall prints, created by Mensura Media. All materials include large character references, pronunciation guides and practice sheets for handwriting practice.

Open the worksheetsView on GitHub

What it does

Features

  • 01

    Japanese materials

    Worksheets and study tools for Hiragana, Katakana, Kanji and vocabulary topics.

  • 02

    English materials

    21 materials for Japanese speakers: alphabet, phonics, sight words, basic vocabulary, grammar and Eiken 5 prep.

  • 03

    Character references

    Large character references and pronunciation guides are included with the practice sheets.

  • 04

    Handwriting practice

    Practice sheets for handwriting, plus reference charts, flash cards and wall prints.
