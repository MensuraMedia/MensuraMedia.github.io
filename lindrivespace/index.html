LinDriveSpace

See what is eating your disk, mount by mount.

A native GTK 3 disk-space explorer for Linux Mint and Debian-family desktops. See every mount and partition at a glance, then drill into folders and files to find out exactly what is eating your disk.

InstallView on GitHub

Not for Windows, macOS or the Windows Subsystem for Linux.

What it does

Features

  • 01

    Mounts overview

    Every mount grouped by physical disk with used, free and total, usage bars amber at 85% and red at 95%, and live USB hot-plug.

  • 02

    Explorer tree

    A sortable tree of folders and files with apparent and allocated sizes, counts, share-of-parent bars and modified dates.

  • 03

    Insight panel

    A squarified treemap, the largest files in the selection, file-type totals and an age histogram.

  • 04

    History

    Usage recorded automatically and charted per mount; a Where-space-changed table diffs two scans folder by folder.

  • 05

    Scan as admin

    Denied subtrees can be re-scanned through a polkit prompt; the elevated helper is a tiny stdlib-only process, never the GUI.

  • 06

    Exports

    Export the tree as CSV or JSON and the treemap as PNG; move to trash with confirmation, open in file manager or terminal.

A closer look

Install

Build and install the Debian package, or run straight from the checkout.

Requirements

  • Python 3.10+ (3.12 on Mint 22)
  • GTK 3.24 + PyGObject
  • python3-psutil, python3-pyudev
  • fonts-ubuntu, policykit-1 (optional)
  • X11 or Wayland session
Debian package
git clone https://github.com/MensuraMedia/lindrivespace.git && cd lindrivespace
scripts/build-deb.sh   # → dist/lindrivespace_0.2.0_all.deb
sudo apt install ./dist/lindrivespace_0.2.0_all.deb
  • scripts/install.sh installs to ~/.local; --system for all users; scripts/uninstall.sh keeps settings and history
  • ./run.sh runs from the checkout with nothing to install
  • Not packaged for Fedora, Arch or openSUSE, but ./run.sh works with the distro's own GTK 3 packages

Full and current instructions: the README on GitHub.
