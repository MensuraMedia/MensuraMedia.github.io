LinMediaDownloader

Download YouTube videos and playlists as MP3 or MP4.

LinMediaDownloader pairs a small Flask backend with a PyWebView native window and delegates all downloading to yt-dlp. It runs as a native desktop window or an ordinary web browser, and binds only to localhost.

What it does

Features

  • 01

    Video & playlist downloads

    Download single YouTube videos or entire playlists as audio (MP3, 192 kbps) or full video (MP4), with a clean cancel at any time.

  • 02

    Real-time progress

    An overall progress circle plus a live bar under the current track; the download table lists each track's length.

  • 03

    Ignore duplicates

    Skips tracks you already downloaded, matched by video id and by original title with at least 80% relevancy, using a hidden manifest.

  • 04

    Playlists manager

    Rename playlists and clean file names in bulk: remove filler words, change case, add number prefixes - every operation undoable.

  • 05

    Built-in player

    A Player tab plays downloaded audio and video over a searchable list; delete a file or add it to a new folder as you listen.

  • 06

    Two ways to run

    Use the native desktop window (PyWebView) or an ordinary web browser; the Flask server binds only to 127.0.0.1.

Install

One command installs Python, ffmpeg and the GUI backend, and adds the app to the program menu.

Requirements

  • Python 3.8+
  • yt-dlp, Flask, pywebview
  • ffmpeg on PATH (audio extraction)
  • Linux or Windows
One command (Debian/Ubuntu/Mint)
curl -fsSL https://raw.githubusercontent.com/MensuraMedia/linux-media-downloader/main/install.sh | bash
  • Re-run the one-command install to update.
  • Uninstall with: bash ~/.local/share/linux-media-downloader/install.sh --uninstall
  • Other platforms and manual setup are covered in INSTALL.md
