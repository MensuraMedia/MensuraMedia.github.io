LinWallpaper

Set one wallpaper across desktop, login and boot screens.

A small GTK 4 + libadwaita app that sets a wallpaper across every screen of a Linux machine: the desktop per monitor, the lock screen and, with your password, the login greeter, boot splash and GRUB menu. No daemon; privileged screens back up files first.

What it does

Features

  • 01

    Five surfaces

    Desktop per monitor and lock screen without root; login greeter, boot splash and GRUB menu with a password on apply.

  • 02

    Simulated monitors

    Each surface is previewed in a fixed-aspect monitor; resizing never stretches the wallpaper.

  • 03

    Fit modes

    Fill, Fit, Center and Stretch; the preview and the applied result come from the same transform.

  • 04

    Wallpaper library

    A thumbnail grid of saved wallpapers with a built-in default; originals are referenced, never copied or modified.

  • 05

    Right-click integration

    An Add to LinWallpaper entry for Nemo, Nautilus, Thunar and Dolphin file managers.

  • 06

    Reversible

    Desktop applies are a settings write with Undo; privileged applies back up files first and support --undo.

Install

One command clones the repo and runs the installer, which adds missing packages and a menu entry.

Requirements

  • python3-gi, gir1.2-gtk-4.0, gir1.2-adw-1
  • gir1.2-gdkpixbuf-2.0, python3-pil
  • pkexec or sudo for privileged screens
One command
git clone https://github.com/MensuraMedia/linwallpapers.git && bash linwallpapers/install.sh
  • Update with git -C linwallpapers pull; no reinstall needed
  • bash linwallpapers/install.sh --uninstall removes the menu entry (--system for a system install)
  • Run without installing with python3 -m linwallpaper.main

Full and current instructions: the README on GitHub.
