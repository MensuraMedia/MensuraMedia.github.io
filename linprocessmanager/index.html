LinProcessManager

Watch, understand and control Linux processes offline.

A desktop process manager and system monitor for Linux, everything in one window, fully offline and with no root required. Live process table and tree, signals and renice, resource history, PSI and a searchable systemd-journal log viewer.

What it does

Features

  • 01

    Live process table

    Every process updated in place; filter by name plain or regex, scope to your own processes, hide kernel threads.

  • 02

    25 sortable columns

    CPU, memory, swap, per-process disk I/O and network rates, threads, nice, OOM score, cgroup unit and more.

  • 03

    Signals & priorities

    Stop, Continue, End, Kill or any signal from a picker; renice presets, CPU affinity; outcomes are verified and reported.

  • 04

    Graphs & disks

    Six system dashboards with 5-minute history, per-filesystem capacity bars and per-device read/write rates.

  • 05

    Journal logs

    The systemd journal with presets, unit and priority filters and severity colouring; saved views are in development.

  • 06

    Fully offline

    Reads /proc, /sys and local journalctl only; makes no network connections, enforced by test gates.

A closer look

Install

Run from the checkout with the system Python; four system packages, no pip and no venv.

Requirements

  • Python 3.10+
  • python3-gi, gir1.2-gtk-3.0
  • python3-cairo, python3-pil
  • Debian/Ubuntu family (Mint first)
  • systemd journal (journalctl)
Quick start
git clone https://github.com/MensuraMedia/linprocessmanager.git
cd linprocessmanager
./run.sh   # == python3 src/main.py  (system python, no pip/venv)
  • System packages: python3-gi gir1.2-gtk-3.0 python3-cairo python3-pil
  • Python floor 3.10; verified on Mint 22 / Ubuntu 24.04
  • The user manual is docs/USER_MANUAL.md

Full and current instructions: the README on GitHub.
