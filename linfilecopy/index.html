LinFileCopy

Copy or sync local folders with a live preview.

A native GTK 3 app for copying and syncing folders between local disks, USB sticks, external drives and local storage arrays. You design a job in a clear form, preview exactly what will change, and never have to type an rsync command.

InstallView on GitHub

What it does

Features

  • 01

    Copy, mirror, two-way

    Mirror always confirms deletions with the exact list; two-way sync is native with a state file and conflict policies.

  • 02

    Live progress

    Bar, speed, time left, files, current file and a speed graph; pause stops rsync's whole process group.

  • 03

    Preview first

    A dry run lists every new, updated and deleted file before anything changes, with a filterable list.

  • 04

    Encrypted drives

    LUKS drives unlock and lock through UDisks2, with an optional keyring to remember passphrases.

  • 05

    Scheduling

    Systemd user timers or cron, including running a job when a drive is connected.

  • 06

    Exact command shown

    The exact rsync command is always shown and can be copied; a headless command runs saved jobs.

A closer look

Install

One line from GitHub downloads the release, verifies it against SHA256SUMS, then installs.

Requirements

  • Linux with GTK 3.24
  • Python 3.10+ with PyGObject
  • rsync 3.1+
  • UDisks2, ionice, systemd or cron (recommended)
One command (Debian family)
curl -fsSL https://raw.githubusercontent.com/MensuraMedia/linfilecopy/main/get.sh | sh
Any distro, user only
curl -fsSL https://raw.githubusercontent.com/MensuraMedia/linfilecopy/main/get.sh | sh -s -- --user
  • Remove a --user install with get.sh --uninstall; for the package: sudo apt remove linfilecopy
  • From a clone, ./install.sh installs the ready-made Debian package; --user installs to ~/.local
  • Run straight from the checkout with python3 -m linfilecopy

Full and current instructions: the README on GitHub.
