LinFileSearch

Search every mounted filesystem live, with no index.

A native Linux desktop file-search utility built with GTK 3 and Python. It searches all mounted filesystems without an index, streaming results live with pause and stop control.

What it does

Features

  • 01

    Three search modes

    Substring, wildcard with find -name semantics, and regular expressions, plus a case-sensitivity toggle.

  • 02

    Every filesystem

    Searches the system root, home partition, data disks and USB drives; pseudo-filesystems are excluded automatically.

  • 03

    Streaming results

    Name, path, size, type, modified and mountpoint in a sortable table with drag-reorderable columns.

  • 04

    Preview pane

    Collapsible metadata and text snippet, with open, show-in-folder, copy path and trash actions.

  • 05

    Search history

    Every run recorded; single-click re-runs a former search with criteria prepopulated, and entries can be bookmarked.

  • 06

    Tray icon

    Closing the window hides the app to the tray; seven dark themes are inherited from the starter framework.

Install

Run directly with the system Python, or do a user-level install with menu entry and tray icon.

Requirements

  • Python 3.8+ with PyGObject
  • GTK 3.24+
  • Pillow
  • gir1.2-ayatanaappindicator3-0.1 (optional, tray)
Run
git clone https://github.com/MensuraMedia/linfilesearch.git
cd linfilesearch
python3 src/main.py   # system python3 with PyGObject (GTK 3)
User install
./install.sh   # install
  • ./install.sh --uninstall removes it
  • ./run.sh creates a venv and installs requirements.txt
  • On Wayland the tray icon depends on the desktop's AppIndicator support

Full and current instructions: the README on GitHub.
