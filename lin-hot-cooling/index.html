Lin Hot Cooling

Cool your Linux machine to match the workload.

A modular thermal management design for Debian-based Linux, currently at the design phase: the technical concept and milestone plan are written and application code starts with milestone M0. The features below describe the v1.0 target.

Follow on GitHub

Design phase: no application code yet; the features described are the target of v1.0.

What it does

Features

  • 01

    Hardware discovery

    Find every sensor, fan, profile and power control on the machine, what can be changed, and which service owns it.

  • 02

    Three categories

    One-tap Idle, Optimal and Intense cooling, each mapped to what the hardware safely supports.

  • 03

    Workload templates

    A catalog from High-Intensity Gaming to Quiet Office, plus your own clones edited in a form or as YAML.

  • 04

    Thermal Agent

    A background service that monitors heat, predicts time to limit and ranks cooling templates; suggest mode by default.

  • 05

    Automation

    Rules for AC/battery, game start and stop, process types, temperature thresholds, lid state and schedules.

  • 06

    Safety first

    Firmware limits are never exceeded, raw EC registers are never written, and a watchdog hands control back on failure.
