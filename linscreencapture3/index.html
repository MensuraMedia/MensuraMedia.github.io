LinScreenCapture 3

Capture and annotate Linux screenshots in one studio.

A screenshot studio for Linux rebuilt on GTK 4 and Python. Capture a region, window or screen with one key and land straight in an editor with arrows, boxes, text, step numbers, callouts, blur and crop.

InstallView on GitHub

Free for education, research and personal projects; commercial use requires permission.

What it does

Features

  • 01

    Capture anywhere

    Region, Region Plus, window and full-screen capture; every capture goes to the clipboard first, then the save folder, then the studio.

  • 02

    Annotate as layers

    Arrows, lines, boxes, text, step numbers, callouts, blur and pixelate are movable, undoable layers with selection handles.

  • 03

    Background agent

    A small agent keeps running after the studio closes; PrintScreen captures anywhere and the tray icon opens the editor.

  • 04

    Library

    A full-stage page of the save folder, newest first, with thumbnails, select-all, copy, duplicate and trash delete.

  • 05

    Works on Wayland

    X11 is verified with XGetImage; on Wayland the XDG desktop portal is tried first, with CLI backends as a last resort.

  • 06

    Keyboard-first

    Single-letter tool keys, rail toggles, zoom shortcuts and a shortcuts window; toasts instead of dialogs.

A closer look

Install

Install the Debian package, or run the installer script for this user.

Requirements

  • Python 3.12
  • GTK 4.14 · libadwaita 1.5
  • Cairo · Pillow · python-xlib
  • XDG portal (Wayland sessions)
Installer script (this user)
git clone https://github.com/MensuraMedia/linscreencapture3.git
cd linscreencapture3
./install.sh --deps
  • Then press PrintScreen: the agent starts at login and PrintScreen copies a region to the clipboard.
  • Debian package, system-wide install and uninstall: INSTALL.md in the repository.

Full and current instructions: the README on GitHub.
